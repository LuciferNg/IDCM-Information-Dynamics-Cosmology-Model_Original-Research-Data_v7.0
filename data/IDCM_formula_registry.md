### 類型標籤

| 標籤 | 意義 | 更新規則 |
|:-----|:-----|:---------|
| **🟢 結構** | 來自 $K = K_{\text{chain}} \otimes K_{\text{tree}}$ 的純代數推導，零自由參數 | 不可修改，除非推導鏈發現錯誤 |
| **🟢 結構修正** | 系統不包含此項會崩潰/不一致（如 RG running、有限深度邊界項、拓撲扇區閉合） | 可新增，但必須附帶「不加會怎樣」的崩潰論證 |
| **🟡 特殊擬合** | 系統有理由保留此項但無法從第一原理推導（如對稱性限制、相空間邊界、唯象必需） | 必須附帶「為什麼不能從結構推導」的說明 |
| **🔴 開放** | 未閉合，需要進一步結構洞察 | 追蹤中 |

## 新增公式規則

每當新增一條公式：

```
1. 表達式（LaTeX）
2. 數值
3. 外部對照值與來源
4. 誤差百分比
5. 類型：🟢結構 / 🟢結構修正 / 🟡特殊擬合 / 🔴開放
6. 「原因」：為什麼是這個類型，結構公式給推導鏈最後一步，修正給「不加會怎樣」，特殊擬合給「為什麼不能結構推導」
```

### 範例：新增一條公式

```
新增：m_W = 80.377 GeV
表達式：m_W = (π/2) · ε · M_P · B^(-L)
值：80.377 GeV
外部：PDG 2024: 80.377 GeV
誤差：0.0%
類型：🟢 結構
原因：m_W = (π/2)·ε·M_P·B^(-L) = (π/2)·0.1545·1.22×10¹⁹·4^(-6.625) = 80.38 GeV
      來自樹尺度 M_P·B^(-L) 乘以 ε·π/2 的幾何因子
```

### 禁止

```
❌ 「因為接近實驗值」——這不是原因
❌ 「因為泰勒展開到 n 階」——除非系統不展開會崩潰
❌ 「因為設 α = 0.0073」——除非 α 有結構公式
```
