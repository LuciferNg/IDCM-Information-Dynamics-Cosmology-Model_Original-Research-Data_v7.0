# 因果域、因果視界、同步相關長度：定義與區分

---

## 1. 三個概念的定義

### 1.1 哈伯視界 $D_H$（Hubble Horizon）

$$D_H = \frac{c}{H_0} \approx 4395.8 \text{ Mpc}$$

**物理意義：** 退行速度等於光速的距離。在標準宇宙學中，這是**最大可能的因果連通距離**——距離超過 $D_H$ 的兩個事件，沒有任何信號（包括光）可以在宇宙年齡內交換。

**在 IDCM 中的角色：** 宇宙可渲染區域的**最大尺度**。W-field 的一致性必須在至少 $D_H$ 尺度上維持，否則宇宙的不同部分會完全 decohere。

### 1.2 同步相關長度 $\xi$（Sync Correlation Length）

$$\xi \approx 105 \text{ Mpc}$$

**物理意義：** W-field 的**內稟相關長度**——在沒有 sync node 充當中介的情況下，W-field 能維持相位相干性的最大距離。超過 $\xi$，W-field 的 wavefront 會自然 decohere。

**在 IDCM 中的角色：** 宇宙可渲染區域的**最小一致性單元**。$\xi$ 是 W-field 的固有屬性，類似於量子場論中的關聯長度。

### 1.3 結構比率 $N_h$（Structural Ratio）

$$N_h = \frac{D_H}{\xi} = \frac{c}{H_0 \xi} = 16\varphi^{-2} = 41.8885\ldots$$

**物理意義：** **不是一個「數量」**，而是一個**無量綱比率**——哈伯視界內可以容納多少個同步相關長度。它告訴我們 W-field 需要跨越多少個 correlation length 才能覆蓋整個可觀測宇宙。

**推導：**

$$\frac{c}{H_0 \xi} = \frac{2}{\varepsilon \beta} = \frac{2}{(\varphi^{-1}/4)(\varphi^{-1}/2)} = \frac{2}{\varphi^{-2}/8} = \frac{16}{\varphi^{-2}} = 16\varphi^{-2}$$

**精確數值：** $N_h = 16\varphi^{-2} = 16 \times (2/(\sqrt{5}+1))^2 = 16 \times 4/(6+2\sqrt{5}) = 64/(6+2\sqrt{5}) = 41.8885\ldots$

**這是一個精確的結構推導，不是觀測擬合。**

### 1.4 因果域數量 $N_d$（Causal Domain Count）

$$N_d = 44$$

**物理意義：** $z=0.6$ sync transition 時實際參與同步的**因果域數量**。這是一個**物理觀測量**，由 DESI DR2 的 $z=0.6$ BUMP 特徵推斷。

**點解 $N_d \neq N_h$？**

| 量 | $N_h$ | $N_d$ |
|:---|:------|:------|
| 本質 | 無量綱比率 | 整數計數 |
| 推導 | 從遞迴常數精確推導 | 從 $z=0.6$ sync transition 觀測 |
| 數值 | $41.8885\ldots$ | $44$ |
| 意義 | 「$\xi$ 在 $D_H$ 內放幾次」 | 「$z=0.6$ 時有多少域同步」 |
| 是否整數 | 否 | 是 |

**$N_d$ 與 $N_h$ 的關係：**

$N_d$ 不是 $N_h$ 的四捨五入。兩者不同的原因：

1. **$N_h$ 是今天（$z=0$）的比率**，在 $z=0.6$ 時，哈伯參數 $H(z)$ 更大，所以 $D_H(z)$ 更小，$N_h(z=0.6) = D_H(z)/\xi \approx 30$
2. **Sync transition 涉及的是 3D 空間中的域，不是 1D 線性排列**——表面域數 $\sim N_d^2$，體積域數 $\sim N_d^3$
3. **$N_d = 44$ 是沿觀測方向橫跨的域數**，對應於 $z=0.6$ 球殼上的同步事件

### 1.5 「42」

$$42 \approx \lfloor N_h \rceil$$

**沒有物理意義。** 這是 $N_h$ 的四捨五入近似值。不應在文檔中使用。

## 2. 它們在公式中的角色

### 2.1 各常數的公式

| 符號 | 數值 | 公式 | 推導方式 |
|:----|:----:|:-----|:---------|
| $D_H$ | 4395.8 Mpc | $c/H_0$ | 定義 |
| $\xi$ | 105 Mpc | $c/(H_0 N_h)$ | 校準 |
| $N_h$ | 41.8885 | $16\varphi^{-2} = 2/(\varepsilon\beta)$ | **結構推導** |
| $N_d$ | 44 | $z=0.6$ sync transition 觀測 | **物理觀測** |

### 2.2 MERA 深度公式

$$583/2 = 44 \times (6+10\kappa) = N_d \times (6+10\kappa)$$

$$\log_\varphi\left(\frac{D_H}{L_P}\right) = N_d \times (6+10\kappa) + \varepsilon^2(1-\varepsilon-\varepsilon^2)$$

這裡用的是 $N_d = 44$（因果域物理計數），**不是** $N_h$。

### 2.3 為什麼是 $N_d$ 而不是 $N_h$？

MERA 張量網絡的深度由**物理域數**決定，而不是由**結構比率**決定。每個因果域 $N_d$ 需要 $(6+10\kappa)$ 層 MERA 張量來將 consistency 從 $\xi$ 尺度 renormalize 到 Planck 尺度。而 $N_h$ 是不同費曼圖中的結構比率，不出現在尺度分離的深度公式中。

## 4. 檢查清單

使用這三個數時，問以下問題：

1. **這是一個比率還是一個計數？**
   - 比率 → $N_h = 41.8885$
   - 計數 → $N_d = 44$

2. **這是從結構推導還是從觀測？**
   - 結構推導 → $N_h$（精確）
   - 觀測 → $N_d$（可能隨未來數據微調）

3. **這是從 $z=0$ 還是 $z=0.6$？**
   - $z=0$ → $N_h$（今天）
   - $z=0.6$ → $N_d$（sync transition 時期）

4. **42 出現了嗎？**
   - 如果看到 42，它是 $N_h$ 的近似 → 用 $N_h = 41.8885$ 或 $N_d = 44$ 取代
